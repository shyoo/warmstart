# Warmstart CLA signers

This is the public record of people who have accepted the
[Warmstart Individual Contributor License Agreement](CLA.md). A GitHub login can change; the numeric
account ID and the linked signing comment identify the account that signed. The CLA commit links to
the exact document accepted rather than the moving version on `main`.

The maintainer adds a row only after verifying that the linked comment contains the declaration in
`CLA.md`, including the permanent CLA link, and was posted by the recorded account. The record is
added before the contribution is merged.

| GitHub account | Account ID | Signed at (UTC) | Pull request | Signing comment | CLA version | CLA commit |
