The first release. Two candidates came before it: `rc.1` proved the pipeline, `rc.2` was
installed on a Mac and a Windows machine and drove real agents from both. This is `rc.2`'s tree
with the README brought up to date, published from a public repository — so it is also the first
build whose binaries carry a build attestation, and the first one an installed Warmstart will
offer as an update.

## Upgrading

**From `rc.2`:** install over it. Same database schema (v73); nothing to do.

**From `rc.1`:** install over it. The database moves from schema v71 to v73 on first start; the
migrations are forward-only, so `rc.1` will refuse the data afterwards. That is correct.

**From a pre-rename build:** if you ever installed this as **Multi Agent Controller**, uninstall
that app first (Windows: *Apps › Installed apps*; macOS: drag it out of *Applications*). The
application id changed with the name, so the installer cannot replace it — it would sit beside
Warmstart with the same icon, and its shortcuts would keep opening an empty fleet. Your data is
safe: Warmstart adopts the old data directory on first start and keeps every project, worker and
task.

## What it does

- Runs the coding-agent CLIs you already subscribe to — Claude Code, Codex, Antigravity, Muse — as
  a fleet: each account a *worker* with its own quota, each task a *run* in a pooled git worktree.
- Schedules against the subscriptions' windows: quota-aware routing, preemption before a window
  closes, prompt-cache-aware compaction timing, and a per-task cost with its arithmetic shown.
- Lands work for you under a finish policy (`commit-and-merge`, PR, or ask) and never discards a
  branch it could not land — those surface under **Loose ends**.
- Plan & Split, Plan & Execute, and Debate: several agents argue a question, an organiser resolves
  it, and the thread keeps the citations.
- Remote access: pair a second desktop over Tailscale and drive the fleet from there, or answer a
  task's question from your phone.
- Says why when something will not start: a daemon that refuses — a newer database than the build
  understands, an unwritable data directory — is reported in its own words within a second.

## Known problems

- **Windows** builds are unsigned; SmartScreen warns on first run (see below).
- Linux is not built and not supported.
- Pre-alpha: one maintainer, a real user base of one until today. Issues are read.
