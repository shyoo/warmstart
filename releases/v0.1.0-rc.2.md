The second release candidate, and the first cut from the tree its author actually runs. `rc.1`
was tagged one commit before a 25-commit merge and understood database schema v71; this build
understands v73 and contains everything that merge held. Still a **release candidate**: installed
apps polling for updates will not see it, and the final `0.1.0` is what they will see first.

## Upgrading

**From `rc.1`:** install over it. The database moves from schema v71 to v73 on first start; the
migrations are forward-only, so once this build has opened your data, `rc.1` will refuse it with
*database schema v73 is newer than this build understands* — which is correct, and the reason to
keep going forward.

**From a pre-rename build:** if you ever installed this as **Multi Agent Controller**, uninstall
that app first (Windows: *Apps › Installed apps*; macOS: drag it out of *Applications*). The
application id changed with the name, so the installer cannot replace it — it would sit beside
Warmstart with the same icon, and its shortcuts would keep opening an empty fleet. Your data is
safe: Warmstart adopts the old data directory on first start and keeps every project, worker and
task.

## What's new since `rc.1`

- **The window says why orchestratord died.** A daemon that refuses to start — a newer database
  than the build understands, an unwritable data directory — is now reported in its own words
  within a second, instead of *Starting orchestratord…* for twenty seconds and *did not answer*.
- **Plan & Execute**, a plan kind with one executor and no review turn, beside Plan & Split.
- **Codex's reasoning effort is selectable**, matching Claude and Muse, measured against a live
  account.
- **Directory grants**: an agent can ask for a directory it needs (`request_directory`), a grant
  is carried down a task's lineage, and an attached repository's `.git` is granted with it.
- **The quota-preemption card's wrap-up buttons stopped scattering**, and a hand-off chosen during
  the warning can name where the work goes.
- **Finishing a conversation no longer races Retire it**; empty-branch retirement after a finished
  task works.
- **Phone**: answer the question on the task itself rather than resolving it from a list.
- **First-run setup guidance and a welcome tour**; the *Changes in this task* panel starts
  collapsed; the zoom badge always shows its percentage.
- **Quality Review** list loads batch their task fetches and use a new index; gradable counts fixed.
- **Statistics** scatters read higher-is-better on every axis, and hover no longer shoves the chart.
- **Routing Model** page: *Summary* instead of *Abstract*, coloured section headers, the weight
  coefficients explained, the 3D trade-off plot retired.
- User-facing copy rewritten across the app in a direct developer register.
- Fixes: a leaked `GIT_DIR` that re-initialised the trunk from a WSL-bridged run; a Windows
  regression that emptied a spawned child's `PATH`; an idle-turn watchdog that now defers for
  active child processes; a landing failure carried into a reassigned run; orphaned compaction asks
  named and dead ones verdicted.

## Known problems

- **macOS** builds are signed and notarised, and the suites pass, but no real agent has yet been
  driven end to end from a shipped bundle. That is still what a candidate exists to find out.
- **Windows** builds are unsigned; SmartScreen warns on first run (see below).
- Linux is not built and not supported.
- An installed `-rc` will offer the final `0.1.0` as an update, but never a later `-rc`.
