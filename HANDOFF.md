# Warmstart — Session Handoff
**Current design decision:** Analytics › Routing Model is written up and set as a **paper** — title, abstract, contents, five numbered sections in one serif column, tables captioned and ruled booktabs-style, the arithmetic typeset by KaTeX from the scheduler's own published formula strings — because it is the page where an operator decides whether to trust the scheduler, and a scoreboard invites a glance where a paper invites checking. Statistics reads the last 200 finished tasks or all of them, at the reader's choice. Global includes System (default), Light and Dark appearance preferences; System follows live OS changes. The window's caption area *is* Warmstart chrome — the native title bar is hidden and only the platform's own window buttons remain, overlaid at one end, while panel, history, refresh, zoom, the app name and the global **New task** fill the rest of that one strip. The panel toggle removes the panel and its handle but the work pane remains explicitly in the flexible grid column, so the whole page stays visible. The composer is one modal everywhere and its head row asks the project first: a project route preselects (but never locks) it, and elsewhere the operator must choose one.
Warmstart: a scheduler that routes coding-agent tasks to the worker, session and moment
where they are cheapest. Electron shell + `orchestratord` daemon. Windows now; macOS/Linux built and
started in CI, never run against a real agent CLI.

## Standing decisions worth not relitigating

⛔ The invariants live in `AGENTS.md`; these are the ones most re-argued by somebody who has not read it:
- **Daemon, not all-in-Electron.** The premise is unattended progress across quota windows.
- **Deterministic scheduler; LLM on judgment events only.** A loop running every 10s for weeks must not bill anything, and the fleet survives with no controller at all.
- **PTY-hosted CLI, transcript for state.** We own stdin, so `/compact` is a function call. ⚠️ ANSI parsing determines state in exactly one declared place - a quota reading. Never a session's state.
- **Capabilities and objectives are data.** No `if (adapter === …)`, no `if (mode === …)`.
